# SelfPublish Studio

A full-stack self-publishing platform for managing books, quotes, and publishing workflows.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express

### Database
- Supabase

## Installation

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file based on `.env.example`.

## Project Structure

```
backend/
frontend/
schema.sql
```
